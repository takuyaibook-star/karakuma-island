# 畑の試作用素材

meadow.png：farm-v3の土・芽を除き、草地だけにした背景。左の水桶・じょうろと左下の種箱を維持。
crops.png：4列×5行の透過atlas。左からにんじん、キャベツ、かぼちゃ、スイカ。今回の実装では左列の上3行だけ使う。下2行や他の野菜は採用・実装済みではない。

生成は組み込み画像生成機能で行った。条件は各-prompt.txt。元の生成画像をそのまま保存し、ゲーム内で切り出して描画する。葉はデフォルメされており、ユーザー指定により形を修正していない。カラフルは成熟した作物だけにゲーム内で色を重ねる試作表現。

土はsoil-dry-v2.png（水やり前）／soil-wet-v2.png（水やり後）の独立PNG。soil-grass-v2.pngが耕す前。最初のイラストのふかふかな土と草の縁を参照し、背景には焼き込まない。生成は組み込み画像生成、条件は同名-prompt.txt。4列×2行は操作試作の仮設定。PNGの表示範囲と農地の状態はview.mjs / farm.mjsで別々に管理する。

草地と乾／湿の土は同じ1280角の配置を指定して作成。描画の共通切り出しは(64,256,1152,800)。生成のため厳密な画素一致は保証せず、使用寸法で視覚確認する。
にんじんはscene.mjsの明示した切り出し・根元アンカーを使用し、余白の自動詰めはしない。成熟画像をマス内に縮小しない。畑の通路やタップ範囲を作物の葉に合わせて変えない。
