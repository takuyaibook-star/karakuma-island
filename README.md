# カラくまちゃんアイランド

淡い水彩・絵本調の世界を自由に歩き、畑でにんじんを育てるスマートフォン向け試作です。

**初期マップ：<https://takuyaibook-star.github.io/karakuma-island/?v=13>**

家の右手の畑への道を上へ進むと畑に入ります。畑の下の道を進むと村へ戻ります。直接の畑URLは <https://takuyaibook-star.github.io/karakuma-island/?map=farm&v=13>。マップを移っても同じBGMが流れ続けます。

## 操作・育成

- 画面下半分の好きな位置からスワイプ。指を離すと停止。矢印/WASDでも移動。
- 画面下半分を短くタップすると、近くに出ている操作を実行。操作がない時は何も起きません。村では上半分の道をタップして移動もできます。
- 畑に近づくと、野菜やマスの上に耕す/種まき/水やり/収穫のボタンが出る。
- 新規は4マスだけ開墾済み。作業に必要な道具は、所持していれば持ち替え不要。左下か鞄で見た目の装備を切り替えられます。
- クワは耕す10回で使い切り。各マスは10回収穫で耕し直し。開墾にはすごいクワを1マス1個使う。試作設定で道具を補充できる。
- 水やりから5秒で芽。芽から2分で育ち中、芽から5分で収穫。ボタンに残り時間を表示。
- 水は3回で空になり、じょうろボタンに「からっぽ」と表示。水やり・水くみでじょうろを自動で持ち、マップ移動、じょうろボタンでしまう、別の道具を持つまで持ち続けます。最初の畑のすぐ上の水くみ場に近づき補充する。
- 「鞄」でアイテムボックス。通常とカラフルは別アイテム。種は試作中は使い放題。
- ♪でBGM ON/OFF。初期ON、実操作後に再生。効果音は試作設定で切替。

畑・持ち物・水・装備は端末のブラウザ内に保存します。旧保存をバックアップしてから新形式へ移行します。別の端末とは共有されません。ログイン、共通DB、コイン連携は未実装。にんじんは成熟時に地面が乾き、乾燥が1時間続くと枯れます。それまでは収穫できます。未水やりの種は枯れません。枯れた作物は近づいて片づけると別アイテムとして鞄へ入ります。芽の段階は共通の「枯れた草」、実が見える段階は「枯れたにんじん」などの専用IDです。現在育てられるのはにんじんだけで、枯れ画像は仮デザインです。正式な道具入手イベントと各野菜の正式な枯れ画像はユーザー指定で課題に残します。新しい種埋め・キャラ色合わせ・道具アイコンは組み込み済みです。その他は[TODO.md](TODO.md)を参照してください。

## 開発を引き継ぐ

画像は採用が確定した素材だけGitHubに保存します。比較案・比較一覧はローカルで管理します。スイカの4色断面は画像/仕様だけを採用し、育成は今回追加していません。

最初に[AGENTS.md](AGENTS.md)、[PROJECT_STATUS.md](PROJECT_STATUS.md)、[TODO.md](TODO.md)を読み、既存ブランチ・remote・未コミット変更・GitHub最新を確認してください。他環境の変更を破棄しないでください。

index.html/shell.mjsが音楽を常駐させ、village.htmlと畑のマップだけを切り替えます。HTML/CSS/標準JavaScript/Canvas 2Dの静的サイト。起動にビルド・npm依存・APIキー・.envは不要です。

```sh
git clone https://github.com/takuyaibook-star/karakuma-island.git
cd karakuma-island
python3 -m http.server 5193 --bind 127.0.0.1
```

<http://127.0.0.1:5193/> で確認します。使われているポートのサーバーを止めず、別ポートを選んでください。file://で直接開かないでください。

```sh
node --test tests/*.test.*
```

Node 20以上。既存の移動15項目に加え起動、旧描画API、成長境界、水、アイテム、保存、経路、装備表示、効果音、収穫演出、マップ接続を確認します。自動テストはiPhone実機の代用ではありません。

## 公開と素材

GitHub Pagesはmain/rootを配信。資料更新でも配信処理が走ります。コミット保存と本番公開を区別し、内容を確認してから反映してください。_headersはNetlify形式でPagesのヘッダー設定には使われず、CSPはHTMLのmetaです。

背景・キャラクターは本作向けの提供/生成素材。各生成条件と採用状態はassets/READMEとPROJECT_STATUSを参照。港・野菜の未実装案を実装済みと混同しないでください。

BGMはユーザーが用意したMotionElements音源のゲーム用AAC。Stock media provided by MotionElements.com。一律のオープンソース素材ライセンスは付与していません。

## ヘッドレスでの操作確認

インストール済みのPlaywrightとChromeで `node tests/browser-smoke.cjs`。`PLAYWRIGHT_MODULE`と`CHROMIUM_PATH`でインストール済みの場所、`TEST_URL`でローカル確認サーバーを指定できます。確認画像は既定で `/tmp/karakuma-v7-checks` に出力し、GitHubへ保存しません。自動ダウンロードや有料APIの呼び出しはありません。

乾湿・枯れの画面確認は同じ環境変数で `node tests/browser-moisture.cjs`。専用ブラウザ内のテスト保存のみを使用します。保存形式v3へ移行する際は元の文字列を `karakuma-island:farming:v1:backup:before-v3` に残し、既存の成熟作物には最低1時間の猶予を設けます。

耕す/開墾/水やりでは、対象の畑の上でクワやじょうろが浮いて750ms作業します。じょうろを傾けると水滴が土へ落ちます。からくまちゃんは道具を持ったままです。演出で水やクワを追加消費することはありません。

水桶・じょうろ・種箱・クワは底面だけ通行を止め、裏へ回れます。待ち時間も各野菜の上に表示します。

水やり・収穫などの作業表示は、近づいた野菜だけに出ます。残り時間は各野菜の上に表示。樽等の足元へ薄い草を重ね、浮く道具は作業表示より手前に描きます。

画面下半分のタップ決定・スワイプ移動と二重消費防止は `node tests/browser-tap.cjs` で確認します。表示中の操作だけ実行します。
